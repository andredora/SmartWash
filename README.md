## Project Overview
**SmartWash** is a mobile-oriented web application designed to improve the experience of users who rely on self-service laundries.  
The platform allows users to **find nearby laundries**, **check real-time availability of washing machines and dryers**, and **reserve machines in advance**, reducing waiting times and improving convenience.

The project was developed within the scope of the **Human-Computer Interaction (HCI / IHC)** course, with a strong focus on **user-centered design**, including **personas, scenarios, task analysis, and functional and non-functional requirements**.

---

## Key Features
- Search for nearby laundries by location  
- View availability of washers and dryers  
- Reserve machines for a specific time slot  
- Mobile-first interface design  
- Clear task flows based on user scenarios

## Getting Started

### Prerequisites
- Node.js installed on your machine

---

### Installation
```bash
cd smartwash/src
npm install
```

---

### Running the Project

#### Development Mode
```bash
cd smartwash/src
npm run dev
```
> ⚠️ Remember to set the browser view to **mobile mode**.

#### Production Preview
```bash
cd smartwash/src
npm run build
npm run preview
```

Then:
- Click **“Open with”** (square icon with arrow in the browser)
- Select **React-vite-app**
- Open the application  
> ⚠️ Remember to set the browser view to **mobile mode**.
